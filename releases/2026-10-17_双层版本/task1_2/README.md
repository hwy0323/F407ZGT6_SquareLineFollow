# 双层版本 1-2：A 点出发绕场一圈

[BIN](固件/F407ZGT6_Task1_OneLap_Remote_STBY_PB15.bin) · [ELF](固件/F407ZGT6_Task1_OneLap_Remote_STBY_PB15.elf) · [main.c](main.c) · [接线](../接线.md)

从 A 点沿 AB 朝 B，按 PA15 KEY 或 DAP 单字节 G 启动，依次经过 B、C、D，回到 A 点停车。上电保持停车，X 或 KEY 停止。

原始记录 [run_20261017_000937.csv](logs/run_20261017_000937.csv) 结束于 `EVENT,STOP,15999,A_REACHED_ONE_LAP,turns=4`，共 15.999 秒；用户确认效果正常。最后在 A 点停止，不要求再把 A 弯转完。

采用成功正方形循迹逻辑，真弯里程窗口中心 5100／11299／17567／23793 计数，各 ±900；不是每个弯都由 IMU 固定原地转满 90°。宽黑特征日志不代表现场必有库线，普通黑胶带也可能触发多个探头。

今日撤除车库线的场地验收，不能直接证明所有车库线同时存在时均能抗干扰。编译和使用见 [总览](../README.md)。
