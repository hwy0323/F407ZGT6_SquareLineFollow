# 双层版任务入口 3-B：BC 库内出发，固定到 B

用户在今天到 D 的现场测试通过后表示“按这个逻辑 B 应该也没问题”，要求一并上传。本目录收录既有 PB15 到 B 源码和固件，不改行车参数；B 的今天状态是用户基于 A／D 表现作出的判断，不新增今天的运行日志。

## 路线与操作

BC 库内，车头朝外、八路 FF → F100→R50→F180→R60→F200→F190→B37→R68 → 通过 C 后接管 CD → D 右转 → A 右转 → AB 上停 B。F／B 单位 mm，R 单位度。不启用视觉，STBY PB15。

上电停机，短按并松开 PA15 KEY 或 DAP 发送 G 启动，KEY／X 停止。T 仅用于已经过 C、位于 CD 的续行，不能在库内使用。[统一接线](../接线.md)。

## 历史实测范围

10.11 旧 PC0 线束有两次现场认可：CD 中途续行及 BC 库内整套重跑。原样历史记录保存在 logs，不能当作本次 PB15 双层运行记录。原版在 AB 约 6000 左前计数时触发 EXPECTED_CORNER_MISSING 停车，用户认可位置，但没有 B_REACHED_FROM_BC_GARAGE 正常完成事件。现版沿用这个终点逻辑，菜单不能把保护事件直接作为正常完成。

详细原说明见[历史到 B 版本](../../2026-10-11_任务3_ABCD四版本/B/README.md)。文件名和 READY 中若仍含 UNTESTED，为原固件创建时标记；不因改名而修改 BIN 内容或事件。

## 来源与编译

源码和固件来自 10.12 PB15 task3_B，固件重命名为本目录 3-B，不覆盖历史版本。下载整个仓库后在此目录 make all，依赖上级 build.mk 及根目录 Core／Drivers／链接脚本；BIN／ELF 保存在固件目录。
