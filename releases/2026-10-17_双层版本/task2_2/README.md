## 流程与启动

从 A 点沿 AB 出发 → 循迹经过 B、C、D 三个真弯 → DA 库线定位停车 → 左转 5.46° → 前进 2194 编码器计数 → 左转 41.93° → 倒车 1347 计数 → 右转 44.74° → 停车，不出库。

1347 = 原倒车基准 1146 + 额外 3.5 cm 约 201 计数，按约 5.73 计数/mm 换算。不要把 1347 当成毫米，也不要在 1347 上再加 3.5 cm。各步角度均使用当步开始时的新鲜 IMU 相对变化。

上电保持停机，放好 A 点后短按 PA15 KEY 开始；电脑可发送完整帧 `@SIDE:RUN` 加换行启动，单字节 G 不能替代该帧。KEY／X 可停机，每次复位只运行一轮。使用前先按 [总览](../README.md) 确认场地、负载和线束。

## 连贯与偏差记录

行驶主体连续驱动，接近终点减速；不做末端反复点动或倒回补偿。停电后等待 200 ms 检查，成功后间隔 150 ms 衔接下一步；库线定位后先停稳 1.2 秒。保留必要换向／转向停车，不是所有动作无停顿硬切换。

原精细门槛为直线 ±20 计数、角度 ±0.60°，满足则记 DONE。按本轮用户认可实测设置的连续试验容差为直线 ±40 计数、小于 15° 转向 ±1°、其他转向 ±2.5°；在该范围但超出精细门槛记 DONE_OFFSET，继续下一步。超出连续试验范围或遇 IMU 过期、超时、无进展、航向／行程异常仍停止。不能将 DONE_OFFSET 当作达到原精细精度。
