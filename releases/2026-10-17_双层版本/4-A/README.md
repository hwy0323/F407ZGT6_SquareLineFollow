## 实际流程

BC 倒车车库内，车头朝外，八路循迹全亮 → F100 → R050 → F180 → R060 → F200 五步出库 → 接循迹转 C 弯并对中 → 正常循迹经过 D → 到 A 停车。F 为 mm，R 为度。STBY PB15，不启用视觉；上电停机，KEY 或 DAP 单字节 G 启动，KEY／X 停止。
