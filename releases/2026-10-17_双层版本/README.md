# 2026-10-17 双层版本

本次交付收录今天现场认可的 1-1、1-2、2-1、2-2，以及库内到 A／C／D 的记录与工程，另收录沿用原逻辑的到 B 入口。双层版本是本轮整车装配状态的归档名称：加装上层结构／云台后负载增加，不是软件分两层，也不代表这些固件启用了云台、视觉或 OLED 菜单。

STBY 为 **PB15**。各任务是独立固件，选一个烧录；上电、复位后保持停车。1-1／1-2／2-1／2-2 放在 A 点、车头沿 AB 朝 B、中间灰度探头对线；4-A／4-B／4-C／4-D 从 BC 倒车车库内出发、车头朝外、八路全亮。放好后短按并松开 PA15 KEY 或发送串口 G 启动，运行中 KEY／DAP 串口 X 停止。2-2 每次复位只运行一轮。4-A～4-D 是本轮归档命名，不表示启用发挥一视觉。

## 场地与使用限制

- 1-1、1-2 按今日撤除库线的正方形场地测试；1-1 保留了实际保护停机状态，不保证换场后自动准确识别 B。
- 2-1 使用 BC 倒车库线，撤除 DA 侧方库线；2-2 使用 DA 侧方库线。其他黑胶带、起点、灰度高度或负载变化都可能改变判断。
- 所有现场认可仅对应本轮地图、线束和装配负载，不是任意场地通用标定，也不是已完成多轮可靠性验收。
- 电机停止命令为 0 不代表机械瞬时无滑行。2-2 的精细误差与连续试验容差分开记录，不靠反复点动逼近终点。
- 原题 1-1 限时 10 秒、1-2 限时 30 秒，本次记录分别为 3.586 和 15.999 秒；压点、投影和压线仍由现场观察判定，不能仅靠串口证明。
- 灰度 OUT 接 PC1 的历史实测线束保留；PC1 不是 5 V 容忍输入。未测量 OUT 电平不能认定电气安全，制作 PCB 仍须核对并保护。

## 下载与编译

下载整个仓库，保留根目录 `Core/`、`Drivers/`、`STM32F407ZGTx_FLASH.ld`。本目录依赖它们，单独下载本子目录不足以重编译。使用 CubeIDE 自带 GNU Arm 工具链和 GNU make，不是编译仓库根目录的 OLED 菜单工程。

在仓库根目录打开 PowerShell，例如编译 2-2：

```powershell
cd "releases/2026-10-17_双层版本/task2_2"
make all
```

其他任务将最后一层目录替换为 `task1_1`、`task1_2`、`task2_1`。工具链默认路径沿用本机 CubeIDE 1.19.0；其他电脑可用 `make "TOOL_ROOT=C:/工具链/tools/bin" all` 覆盖。输出在各任务 `build/`，用于直接烧录的已实测原样固件保存在各任务 `固件/`。

1-1、1-2、2-1、2-2、4-A、4-D 均保存对应原实测 BIN／ELF，不通过重新编译替换历史文件。4-C 保留原六步现场固件并另存合并版；4-B 沿用原 PB15 固件。任务 2-2 的主机测试：在它的目录用原生 C 编译器编译 `tests/test_normal.c reference_steps.c`，再运行测试程序。4-C 的主机测试为 `tests/test_C.c`。测试不接触小车。
