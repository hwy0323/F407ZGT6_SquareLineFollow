# 验证记录

日期：2026-10-17。仅本地编译及主机模拟，未连接串口、未烧录、未驱动车轮。

- ARM 固件全量重编译成功，生成 BIN／ELF；链接尺寸 text=51740、data=796、bss=4868 字节，BIN 为 52544 字节。最终文件以 SHA256.txt 为准。
- 自编应用未出现编译警告；仓库共享 HAL／ST VL53L0X API 的已有未使用参数、符号类型等警告，以及 newlib nosys 的 _read／_write 等桩警告仍保留，不能说是零警告构建。
- 两个主机测试程序均使用 `-std=c11 -Wall -Wextra -Werror` 编译通过。
- 分类测试遍历 20～500 mm 共 481 个距离，核对侧停 101～151 mm、倒库 201～251 mm 的完整边界。另测超差波动、无效距离、非法偏移，以及 4 条边的正常线／单灯／中心三灯／库线／真弯／歧义与越界。
- 流程测试覆盖 4 条边×2 种库型共 8 套：停车→F287→丢弃 3 次旧样本→5 次有效读数→退回实测位移→3／5 个入库动作→停机；测距调用时断言左右电机命令均为零。
- 异常测试包括 RangeStatus 无效、API 错误、样本计数冻结、超时、未知类型、回退位置／航向误差、真弯恢复、持续丢线、编码器停滞、IMU 失联、整套时间上限、一圈未找到车位、启动前置条件、完整帧／重复启动／X、UART 错帧／队列溢出、上电按住 KEY 不启动与运行中 KEY 停机。
- 测试直接包含实际 navigation.inc、search_workflow.inc、entry_motion.inc、commands.inc、start.inc，链接实际 search_logic.c 和 entry_plan.c；HAL、编码器、IMU 和测距由主机桩模拟。没有声称在主机上验证真实引脚电平、实际电机惯性、辅助墙光学效果或无压线。

实测前提仍未验证：右侧窗口偏移 74 mm 是半车宽估算；前进 5 cm 后光束能否照进辅助墙；真弯窗口是否适应当前发车点和负载；两套相对入库动作在移动后的车位中是否仍能完全入库。请按 README 的场地边界测试，不将软件测试替代实车验收。
