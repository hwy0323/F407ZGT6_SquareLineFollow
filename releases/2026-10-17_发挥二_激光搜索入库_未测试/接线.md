# 发挥二实板接线（STBY 为 PB15）

依据用户的 F407_2.0实板接线表_2026-10-12.txt。表中 PC0 STBY 已被用户明确改为 PB15；其他线不变。

## 本程序实际使用

| 功能 | F407 引脚 | 模块端／说明 |
| --- | --- | --- |
| Motor A 左前 | PD0、PD1、PE9 | AIN1、AIN2、PWMA |
| 左前编码器 | PB6、PB7 | E1A、E1B，TIM4 |
| Motor B 左后 | PD2、PD3、PE11 | BIN1、BIN2、PWMB |
| 左后编码器 | PA6、PA7 | E2A、E2B，TIM3 |
| Motor C 右后 | PD4、PD5、PE13 | CIN1、CIN2、PWMC |
| 右后编码器 | PC6、PC7 | E3A、E3B，TIM8 |
| Motor D 右前 | PD6、PD7、PE14 | DIN1、DIN2、PWMD |
| 右前编码器 | PA0、PA1 | E4A、E4B，TIM2 |
| 四路驱动公共 STBY | **PB15** | 不接 PC0，不同时接 3V3 |
| 八路循迹 AD0／AD1／AD2 | PB12／PB13／PB14 | 地址选择，不是三路模拟采样 |
| 八路循迹 OUT | PC1 | 本程序按已有数字高电平判黑；OUT 必须 ≤3.3 V |
| ICM IMU | PC10→R，PC11←T | UART4，115200 8N1 |
| 测距 XSH | PC8→XSH | ATK-MS53L0 六针座第 1 针 |
| 测距 SDA | PC9↔SDA | 第 3 针，I²C3 |
| 测距 SCL | PA8→SCL | 第 4 针，I²C3，100 kHz |
| 测距 GND／VCC | GND／5VOUT | 第 5／6 针，按已确认支持 5 V 的模块版本 |
| 测距 INT | 不接 | 第 2 针，本版轮询 |
| KEY1 | PA15 | 按下接 GND，内部上拉 |
| LED | PC13 | 板载，低电平亮 |
| DAP 串口 | PA9→RXD，PA10←TXD | USART1，115200 8N1 |
| DAP SWD | PA13、PA14、NRST、GND | SWDIO、SWCLK、RST、公共地 |

测距头在右侧，窗口朝右且水平，照向车库底边辅助墙，不朝地面。板上外置 PE0 激光笔控制口不是测距模块。

## 已分配但本程序不启用

| 功能 | 保留引脚 |
| --- | --- |
| OLED SCL／SDA | PB8／PB9 |
| 备用串口循迹 TX／RX（主控端） | PB10／PB11 |
| 视觉 TX／RX（主控端） | PG14／PG9，USART6 |
| 上轴舵机／不用的下轴 | PA2／PA3 |
| 外置激光笔控制 | PE0 |
| KEY2 | PE6 |

以上引脚不用于其他功能，也不发送视觉报文、舵机 PWM 或激光笔开启信号。

## 电源

电机板由外接 12 V 电池供电；降压 5 V 给实板及支持该电压的模块，所有信号地共地。实板 5VOUT／GND 需按原表板外接到核心板 5V／GND，插排母本身不等于核心板已供电。不能未经隔离就并接 DAP、USB 和外部多个独立 5 V 电源，也不要把驱动板 3.3 V 输出并到主控 3.3 V 输出。不要插 TF 卡或启用 SDIO，本方案复用了对应引脚。
