# PB15 版接线

只改一根线：**驱动板 STBY → 核心板 PB15（B15）**。PC0 不再连接 STBY；不要把 STBY 直接拉到 3V3，也不要把两个 MCU 输出并联。

| 驱动接口／车轮 | 方向 IN1／IN2 | PWM | 编码器 A／B |
| --- | --- | --- | --- |
| Motor A／左前 | PD0／PD1 | PE9，TIM1 CH1 | PB6／PB7，TIM4 |
| Motor B／左后 | PD2／PD3 | PE11，TIM1 CH2 | PA6／PA7，TIM3 |
| Motor C／右后 | PD4／PD5 | PE13，TIM1 CH3 | PC6／PC7，TIM8 |
| Motor D／右前 | PD6／PD7 | PE14，TIM1 CH4 | PA0／PA1，TIM2 |

| 模块信号 | 核心板引脚 |
| --- | --- |
| TB6612 公共 STBY | **PB15，推挽输出，高使能、低停机** |
| 灰度 AD0／AD1／AD2 | PB12／PB13／PB14 |
| 灰度 OUT | PC1 |
| 灰度 5V／GND | 5VIN／公共 GND |
| IMU R／T | PC10 UART4_TX → R；PC11 UART4_RX ← T |
| IMU V／G | 5V／公共 GND |
| DAP RXD／TXD | PA9 USART1_TX → RXD；PA10 USART1_RX ← TXD |
| DAP SWDIO／SWCLK／RST | PA13／PA14／NRST，另接公共 GND |
| 板载 KEY | PA15，低电平按下 |
| OLED 菜单确认键 | PE6，按下接 GND |
| OLED SCL／SDA | PB8／PB9，I2C1，按屏幕实际额定电压供电 |
| 板载 LED | PC13，低电平点亮 |

PB15 不与 PB12～PB14 的循迹地址线、PA15 的按键冲突。这些新工程不启用 PB15 的 USB、SPI 或定时器复用功能。用于 PCB 时建议 STBY 对 GND 增加 10 kΩ 下拉，保证复位期间保持停机。

本次没有更改视觉、云台或激光接口；这些外设不属于八个任务的实际执行流程，完整 PCB 规划不能仅凭本表推断。全部共地；12 V 不得接 GPIO 或 5 V。PB15 的输出仍为约 3.3 V，迁移不解决驱动板 5 V 逻辑的高电平裕量问题。

PC1 不是 5 V 容忍输入，灰度 OUT 最高电平仍须测量并按需保护，旧版运行成功不是电气安全证明。
