# 10.10 侧方停车分段路线实测记录

本目录归档用户于 2026-10-10 确认效果完美的一轮侧方停车分段实测。记录从直角弯前开始，程序先循迹过一个真实右直角弯，并在车库线处停车；之后由 DAP 串口单步控制，按下表逐步执行。每一步完成后电机停止，串口原始日志一并保存。

本归档是**经实车确认的分段操作记录**，还不是将所有动作拼成一条后按一次 KEY 自动执行的回放固件。复现实验时应按顺序使用两套入口，第一套过弯找库线，第二套逐条发送单步命令。

## 本轮路线

| 顺序 | 动作 | 指令 | 指令目标 | 实测结果 |
| --- | --- | --- | --- | --- |
| 1 | 循迹过真直角弯 | `G` 启动 | 过 1 个右弯，遇库线停车 | 右弯完成；库线灰度 `0x0F`，弯后编码器 A 累计 1479 计数；电机停机 |
| 2 | 原地左转 | `L007` | 7° | IMU 左转 5.46° |
| 3 | 前进 | `F370` | 37 cm | 编码器估算约 38.3 cm |
| 4 | 原地左转 | `L038` | 38° | IMU 左转 41.93° |
| 5 | 倒车 | `B190` | 19 cm | 编码器估算约 20.0 cm |
| 6 | 回正 | `R042` | 约 42°右转，回到起始方向 | 实际右转 44.72°；停稳航向 141.12°，起始方向约 143.91°，偏左约 2.79° |

编码器距离使用现有标定 5.73 计数/mm 估算，并非现场尺量值。原始数据中前进、倒车及转向步骤互不相邻，没有可安全合并的连续同向位移；转弯之间的直行段必须保留，不能跨过转弯合并。

## 单步命令格式

单步固件使用 DAP 串口 `COM14`、115200、8N1。命令为方向字母加 3 位数：`L/R` 后跟角度，`F/B` 后跟毫米数。例如：`L007`、`F370`、`L038`、`B190`、`R042`。脚本会先确认车辆停机及 IMU 数据新鲜，再发送命令；每步自动记录日志，动作结束后电机归零。

运行 PowerShell 示例：

```powershell
cd "releases/2026-10-10_侧方停车路线记录/工程/串口单步控制"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\record_step.ps1 -PortName COM14 -Command L007
```

每步动作会使车辆实际移动或转向。过弯采集脚本 `capture_parking_start.ps1` 通过预检后会自动发送 `G` 启动车辆；单步脚本则会发送其 `-Command` 参数。运行时可按板载 KEY 停止；电脑在场时也可通过串口发送 `X` 急停。重新运行前要将车放回对应记录起点。

## 硬件与接线

以本次记录使用的四驱车线束为准：

| 模块 | F407ZGT6 引脚 |
| --- | --- |
| 左前/左后/右后/右前电机方向 | PD0～PD7 |
| 四路电机 PWM | PE9、PE11、PE13、PE14 |
| TB6612 STBY | PC0 |
| 编码器 A/B/C/D | PB6/PB7、PA6/PA7、PC6/PC7、PA0/PA1 |
| 八路灰度 AD0/AD1/AD2 | PB12/PB13/PB14 |
| 八路灰度 OUT | PC1 |
| IMU R/T | PC10/UART4_TX、PC11/UART4_RX |
| DAP TXD/RXD | PA9/USART1_TX、PA10/USART1_RX |
| 板载 KEY | PA15 |

板卡、驱动板和传感器共地。灰度模块虽用 5 V 供电，仍应按已有 PCB 接线说明核对 OUT 电平与 PC1 的兼容性。
