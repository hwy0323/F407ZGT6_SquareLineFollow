如果漏过目标第一条库线，超过它的窗口就停止，不会把第二条库线当作第一条再入库。漏计／多计非目标库线、到错边、编码器方向错误、搜索超时、持续丢线、灰度或 IMU 过期、转弯超时、编码器停滞等仍保护停机。这些窗口仅适用于本次固定地图、A 点起步、车头沿 AB、当前探头和负载。

## 动作来源与控制

BC／DA 倒库的几何动作来自成功的 2-1：F209→L90→B200；在新通用控制器中换算为 F1198 计数→L9000 百分之一度→B1146 计数，换算基准约 5.73 计数/mm。

CD 侧停复用最新双层 2-2 的计数和相对角度：L546、F2194、L4193、B1347、R4474。直线是计数，转向是 0.01°；B1347 已包含额外 3.5 cm，不要再加一次。CD 车位相对 DA 旋转，同为顺时针行车右侧内库；本次已独立执行 CD 全程并获现场确认，不是仅根据 DA 侧停结果推定成功。

三版共用 common/entry_motion.inc，来自最新双层无末端点动控制器：A／B／C 有符号编码器中位数控制距离，四轮均记录；转向用每一步新鲜 IMU 相对角度，处理跨 360°。直行 PWM 180、近端 135，转向 200／135，按测得进度速度预测滑行，关电后等待 200 ms 检查，成功后停 150 ms 再下一步。BC／DA 库线确认后等待 200 ms，CD 等待 1200 ms。

这不是把旧 BC 倒库的全部控制代码原封不动复制：几何动作保留，但 BC／DA 改为共同的无点动控制及端点检查，必须实车重新验证。直线 ±20 计数、角度 ±0.60° 为 DONE；直线 ±40 计数、小于 15° 转向 ±1°、其他转向 ±2.5° 为 DONE_OFFSET。超出即 END_ERROR 停车，不把超差当成功续行。航向偏离、反向进展、超程、堵转、超时或 IMU 失效也会停机。是否完全入库、是否压库线仍需现场观察。

## 启动与停止

上电和复位后静止；小车必须在 A 点沿 AB 朝 B，中间灰度对线，IMU 有效。短按并松开 PA15 KEY 启动；也可以通过 DAP USART1、115200、8N1 发送对应完整 ASCII 帧（结尾换行）：

- BC：`@TASK4:BC:RUN\n`
- CD：`@TASK4:CD:RUN\n`
- DA：`@TASK4:DA:RUN\n`

上面的 `\n` 表示真正的换行字节，不是反斜杠和字母 n。单字节 G／T 以及别的车位命令不会启动。一轮启动后重复帧无效。KEY／X 停止，完成或取消后必须复位才能新一轮；上电时按住 KEY，松开也不会立即启动。X 在待机时也会锁住本轮，之后需复位。

UART 接收采用 128 字节环形队列；运行中遇串口错误或溢出会停车，不把它们当成启动命令。最初开发时的下行问题未完成根因诊断；本次 BC／CD 均已实际通过 COM14 发送对应完整启动帧，并收到 START 和整套行车记录，证明这两次的下行启动及上行记录可用，不等于解释了旧故障原因。

READY、ENTRY_BEGIN、ENTRY_DONE 和固件文件名均保留创建时的 UNTESTED 身份，BIN 内容与原归档一致；最新实测状态见说明。ENTRY_DONE 本身只证明软件步骤执行结束，BC／CD 另外取得用户现场确认，DA 的实测来源另行注明。

## 文件和编译

各任务的 main.c 是入口，包含共用 common/main.c；entry_plan.c 包含共用动作表，Makefile 的 TASK4_CASE 选择 1／2／3。控制、接收和调度分别在 navigation.inc、entry_motion.inc、entry_workflow.inc。这避免复制三套后只改了一套；不要只拷贝某个入口文件给队友。

下载整个仓库，保留本目录 common、根目录 Core、Drivers、链接脚本及 10.12 build_pb15.mk。在本目录运行：

```powershell
pwsh -NoProfile -File ./compile.ps1 -RunHostTests -ZigPath "你的 zig.exe"
```

也可在任一任务目录用 GNU make 编译，TOOL_ROOT 可覆盖工具链路径。各任务 build 为编译输出，归档 BIN／ELF 在固件目录，文件名均有 UNTESTED。[SHA256](SHA256SUMS.txt)及[验证结果](验证/结果.md)。

编译脚本只编译和运行电脑测试，不烧录、不读串口、不启动车辆。实车验证按 BC／CD／DA 各自记录，不能把一种车位的运行日志当作另一种的证据；换地图、负载或起点后仍需复测。目录名称保留原创建时的“未测试”，避免破坏历史链接，当前状态以本说明为准。
