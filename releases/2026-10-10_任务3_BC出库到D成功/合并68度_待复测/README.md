# BC 出库到 D：直行合并、末次右转 68°（待复测）

按用户要求生成，2026-10-11 编译完成；没有烧录和实车测试。现场成功证据属于上级目录的分段 72° 版本。

## 固定路线

F100 → R050 → F180 → R060 → F200 → F190 → B037 → R068 → CD 循迹到 D 停车。

三次人工前进 F050＋F090＋F050 合为 F190；最后右转由 72° 改为 68°。前五步出库块原样保留，其中最后 F200 不跨出库停车基准与后续 F190 合并，避免进一步改变已标定的停车节点。

F/B 单位 mm，L/R 单位度。各运动步骤之间停 250 ms；第 8 步后停 200 ms，再检查中线和传感器数据，尝试 CD 循迹接管。预检不通过就保持停机，不自动重试，不启用旧版 C 点航向找线或再转一个 C 弯。

上电保持停机。起点必须在 BC 库内、车头朝外、灰度 FF；G 或短按并松开 KEY 才启动整套合并路线。单独 T 只适用于已经过 C 的位置。运行中 X / KEY 停机。

## 为什么必须复测

原三段目标 19 cm，因三次停车超调，编码器累计换算约 22.7 cm。合为一次 F190 后少了两次刹停，终点可能比原分步提前。原右转 72° 的静止变化约 79.18°；改为 68° 也不能保证实际恰好 68°。原试验的物理撤销动作留下约 1.52° 航向差，这个合并版不复现撤销动作。

因此下一次应从相同库内位置先低速验证，重点观察 C 弯位置、是否对上 CD、中途是否触线，以及最终 D 停车位置。不要把本版当作已验证死程序。
