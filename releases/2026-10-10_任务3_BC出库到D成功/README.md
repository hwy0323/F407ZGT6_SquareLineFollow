## 成功版实际执行顺序

F/B 数值单位为 mm，L/R 数值单位为度。转向均是相对当前航向的变化，不是绝对罗盘角度。

| 阶段 | 实际使用的有效指令 | 行为 |
| --- | --- | --- |
| 库内出库 | F100 → R050 → F180 → R060 → F200 | 出库固件收到 G，自动执行五步后停车 |
| C 弯前微调 | F050 → F090 → F050 | 用户现场逐步指挥，每步执行完停车 |
| 调整转弯位置 | B037 | 倒车 3.7 cm 后停车 |
| 通过 C | R072 | 右转指令 72°，现场确认已通过 C |
| CD 到 D | 更换为 CD 固件，发送 T | 正常循迹纠线，识别下一个真右弯 D 后停车，不旋转 D |

试验中撤销过的 R070 及其 L070 物理回滚不列入有效路线。回滚后实际航向与回滚前相差约 1.52°，因此这里保存的是现场分段成功的证据，并不宣称“删除撤销动作后自动重放”已成功。

出库工程上电保持停机，G 或短按并松开 PA15 KEY 启动五步。出库完成后，串口可以逐条发送 F050、B037、R072 等文本命令，末尾加换行；不要一次连发多条。等 STEP_END、左右电机指令均为 0 且车辆停稳后再发下一条。串口为 115200、8N1。

CD 固件上电停机。已过 C 并对准 CD 时发送单字节 T，仅开始 CD 循迹；不要发送 G，G 会重新执行五步出库。T 要求探头中间至少一路见黑、总黑通道不超过 3 路，灰度与 IMU 数据新鲜。任一阶段可发 X 停机，KEY 也用于停止。

## 接线和交接注意

接线仍按 [总 README 当前实测线束](../../README.md#当前实测线束)：

- Motor A 左前、B 左后、C 右后、D 右前；PD0～PD7 为方向，PE9/11/13/14 为 PWM，PC0 为 STBY。
- 编码器 A：PB6/PB7；B：PA6/PA7；C：PC6/PC7；D：PA0/PA1。
- 灰度 AD0/AD1/AD2：PB12/PB13/PB14，OUT：PC1，供电 5V、公共 GND。
- IMU：PC10 → R，PC11 ← T，5V、公共 GND；外设是 UART4。
- DAP 串口：PA9 → RXD，PA10 ← TXD；SWD 使用 PA13/PA14/NRST 和 GND。

PC1 不是 5 V 容忍输入；模块 OUT 电平未实测，不能把已有运行记录当作耐压证明。PCB 仍需核对和保护。

本目录不替换根目录的 OLED 菜单工程。当前车上程序本次未改动，未重新烧录或执行运动命令。
