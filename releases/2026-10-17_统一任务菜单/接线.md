# 统一菜单接线（STBY 为 PB15）

沿用 2.0 实板接线及最新 PB15 STBY，不改现有任务线束。

| 功能 | F407 引脚 | 接法 |
| --- | --- | --- |
| 切题 KEY | PA15 | 板载 KEY；按下接 GND，不论长短都只切下一题 |
| 确认／启动 | PE6 | 外置常开按键另一端接 GND；内部上拉 |
| 激光笔控制信号 | PE0 | 高电平约 3.3 V 亮、低电平灭；只接控制输入，不给激光笔供电 |
| OLED | PB8 SCL、PB9 SDA | SSD1306 I²C，GND 共地；供电及上拉需匹配 3.3 V 逻辑 |
| 驱动公共 STBY | PB15 | 不接 PC0，不同时接 3V3 |
| Motor A 左前 | PD0／PD1／PE9 | IN1／IN2／PWM |
| Motor B 左后 | PD2／PD3／PE11 | IN1／IN2／PWM |
| Motor C 右后 | PD4／PD5／PE13 | IN1／IN2／PWM |
| Motor D 右前 | PD6／PD7／PE14 | IN1／IN2／PWM |
| 左前编码器 A／B | PB6／PB7 | TIM4 |
| 左后编码器 A／B | PA6／PA7 | TIM3 |
| 右后编码器 A／B | PC6／PC7 | TIM8 |
| 右前编码器 A／B | PA0／PA1 | TIM2 |
| 灰度 AD0／AD1／AD2 | PB12／PB13／PB14 | 地址选择；非三路模拟输入 |
| 灰度 OUT | PC1 | 数字高电平判黑，必须保证 ≤3.3 V；PC1 不耐 5 V |
| IMU | PC10 TX→R，PC11 RX←T | UART4，115200 8N1；供电和公共 GND 沿用实板 |
| 激光 XSH／SDA／SCL | PC8／PC9／PA8 | I²C3；ATK-MS53L0 模块，INT 不接 |
| 视觉串口 | PG14 TX→视觉 RX，PG9 RX←视觉 TX | USART6，115200 8N1；K230 GPIO6 RX／GPIO5 TX |
| 上轴舵机信号 | PA2 | TIM5 CH3，180°舵机 |
| 下轴舵机信号 | PA3 | TIM5 CH4，270°舵机 |
| DAP 串口 | PA9 TX→DAP RXD，PA10 RX←DAP TXD | USART1，115200 8N1 |
| DAP 下载 | PA13、PA14、RST、GND | SWDIO、SWCLK、NRST、共地 |
| LED | PC13 | 板载低电平亮 |

电机及舵机由驱动板对应外接电源／稳压 5 V 供电，不从 MCU GPIO 或 3V3 给舵机供电；各模块共地，不并联两个独立 5 V 输出。模块 5 V 供电不代表其信号可直接输出 5 V 接 PC1。激光窗口朝右、水平照向底墙，不朝地面胶带。

运行中 PA15 或 PE6 都会停止任务。PA15 切到 6-1～6-4 的任一项时 PE0 为高，切回其他项为低；这四项仍预留，不会行车。激光笔与主控共地，电源按模块规格单独接，控制端必须接受 3.3 V 高电平，不得反向向 PE0 输入 5 V。若需保证复位期间也灭灯，外部加约 10 kΩ 下拉。测试时不要照射人眼。
