# 菜单工程：F407 双层小车统一 OLED 两键菜单

日期：2026-10-17。当前源码已扩展为 11 项菜单，并增加 PE0 激光笔选择指示；当前固件的编译和烧录结果见[本次更新记录](验证/十一项菜单与PE0.md)。22:03（UTC+8）烧录的是此前的八项菜单，历史记录见[首次烧录](验证/首次烧录.md)，对应旧固件另存于 `验证/八项菜单旧固件_2203/`。新集成版本仍待整车验收。原成功工程、固件和行驶参数保持不变。STBY 仍为 PB15。

## 两个按键，沿用 Git 原菜单

- PA15 板载 KEY：短按并松开切换下一题；按住再久也不会启动。
- PE6 外置确认键：按下接 GND，按下并松开启动当前屏幕选中的题目。
- 等待舵机、等待视觉、预检或行驶期间，按任意一个键均中止，不切换任务。DAP 串口单字节 `X` 也可停车。
- 上电显示 `1-1`，不自动行车。按住按键上电不会自动启动，必须先松开再重新按。
- 完成显示 `DONE`，保护停车显示 `STOP`，发挥三显示 `RESERVED`。保留约 1.5 秒后，电机关闭，主控软件复位回 `1-1` 菜单。复位只清运行状态，不擦写 Flash，不自动恢复上次任务，也不移动小车回起点。
- 每轮开始前重新摆车。不要把上次已停在车库里的车直接启动为 A 点出发任务。

菜单循环：`1-1 → 1-2 → 2-1 → 2-2 → 3 → 4 → 5 → 6-1 → 6-2 → 6-3 → 6-4 → 1-1`。屏幕保留原菜单的三行编号和中间选择框；本版切题为逐项显示，没有动画排队后意外选错题。两键同时松开时确认优先，不先跳到下一题再启动。

PE0 是激光笔控制信号，高电平约 3.3 V。以屏幕中间的选中项为准：选中 6-1、6-2、6-3、6-4 就输出高电平，不用按启动键；其余七项输出低电平。上电默认 1-1，激光笔关闭。6-x 按确认后仅显示 `RESERVED`，指示灯保持亮，约 1.5 秒后复位回 1-1 并关闭；错误处理、硬件异常处理和软件复位前均拉低 PE0。上电及复位期间 GPIO 尚未初始化，若要求全程可靠关闭，应在外部控制端加下拉电阻。

## 视觉和舵机

只在确认任务 3／4 后启动视觉联动，不在切题时发识别命令：

- 任务 3：PA2 上舵机 150°，PA3 下舵机 90°。
- 任务 4：上 150°、下 75°。
- 上轴按 180°、下轴按 270°换算脉宽；上电 PWM 为 0。等待至少 1 秒后才请求对应视觉任务。等待只是定时，不是舵机角度反馈。
- MV/1 协议校验会话、序号、任务号和识别内容，先保存并 ACK 结果，再预检 200 ms。无有效结果、FAIL、超时、换会话或通信错误均不出发；行驶时视觉链路失效会停车。
- OLED 在识别等待时显示 `SERVO`／`WAIT`，预检后显示 `START` 和识别结果。行驶期间保留画面，不做阻塞式整屏 I²C 刷新，避免影响 10 ms 运动调度；结束后更新状态。

基础题、发挥二不依赖摄像头在线；激光只在任务 5 初始化、停车测距，不阻塞其他行车任务。OLED 未初始化成功则拒绝启动，菜单状态下每秒重试屏幕。

## 编译和入口

下载完整仓库，保持本目录位于 `releases/` 下；不要只拿 main.c，也不要误用仓库根目录的旧菜单 Makefile 或历史 `.project`。

```powershell
cd 本目录
powershell -ExecutionPolicy Bypass -File .\compile.ps1
```

编译脚本只执行主机测试及 ARM 构建，不连接 DAP、不打开串口、不烧录、不发送行车命令。默认工具链与之前工程一致，可通过参数覆盖 Make／Zig 路径。若使用 CubeIDE，应以本目录 Makefile 作为外部构建入口，而不是导入旧任务的生成文件。

- 主入口：[main.c](main.c)，硬件、按键分发、OLED 和故障停车。
- 菜单／任务状态：[menu_app.c](menu_app.c)，两键去抖：[keys.c](keys.c)。
- 单任务适配：[native.c](native.c) 和 `native_*.c`。旧控制器在独立 C 编译单元中复用，避免状态互相覆盖；同名动作辅助函数只加链接前缀，不更改计算。
- 正常完成判断：[completion.c](completion.c)。只有对应任务原生完成事件才显示 `DONE`，不把任意停止当作成功。
- 烧录文件：`固件/F407ZGT6_AllTasks_OLED_Menu_STBY_PB15.bin`，地址 `0x08000000`，对应 ELF 和[哈希](SHA256SUMS.txt)一并提供。
- 当前已烧录版请先用 PA15 切题，再由 PE6 或完整帧 `@MENU:RUN` 加换行启动。22:08 实板发现远程切题帧 `@MENU:NEXT` 含 X，被急停接收拦截，尚未修复；不能按主机解析单测误认为它在实板可用。单字符 G／T、旧任务启动帧及缺换行不启动。运行期间不接受切题，发生 UART 错帧／溢出则中止。

## 来源和验证边界

直接复用双层版本 1-1／1-2／2-1／2-2 和 3-A／B／C／D；C 版使用末段连续 F250，A／B／D 保留各自出库及循迹衔接。任务 4 复用最新六分支版本，任务 5 复用 237 mm 分界版本。OLED 字库、SSD1306 驱动、三行布局来自 Git 上现有菜单，不另换显示引脚或驱动。

本轮主机测试包含 11 个菜单项、PE0 四项亮／其余灭／循环与复位关闭、两键、长按 PA15 不启动、运行中停车、完整串口帧、基础任务路由、四种罗马数字、六张卡、先舵机后识别、稳定预检、重复／迟到结果、通信失败、四项预留不行车和停止后复位。另回归实际复用的 24 条六分支导航、六套运动、激光 2002 个距离分类及四边两类的 8 套流程、云台 PWM。测试记录见[主机结果](验证/主机测试.txt)和[ARM 构建](验证/ARM编译.txt)。主机桩不代表真实电平、电机惯性和无压线已验证。
