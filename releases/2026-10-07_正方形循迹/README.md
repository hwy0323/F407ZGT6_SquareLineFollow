# 10.7 正方形循迹

本目录保存 2026-10-07 现场确认正常的四弯正方形循迹版本。从 B 点出发，车头朝 C 点，按板载 KEY 或通过 DAP 串口发送 `G` 后启动；依次完成 B→C→D→A→B 的 4 个真实右直角弯后停车。停机时 TB6612 的 STBY 拉低。

2026-10-08 修正文档中的里程来源、IMU 外设名称和归档目录编译方法，固件与原始日志不变。

## 接线与启动

完整电机、编码器和模块接线见 [仓库首页](../../README.md#当前实测线束)，本版关键接口如下：

| 功能 | 接线 |
| --- | --- |
| 灰度 AD0 / AD1 / AD2 | PB12 / PB13 / PB14 |
| 灰度 OUT | PC1 |
| 灰度电源 | 5V 接 5VIN，GND 接公共 GND |
| IMU R / T | PC10／UART4_TX → R；PC11／UART4_RX ← T |
| DAP RXD / TXD | PA9／USART1_TX → RXD；PA10／USART1_RX ← TXD |
| TB6612 STBY | PC0 |
| 板载 KEY | PA15，低电平按下 |

IMU 是 **UART4，不是 USART3**。本版使用 AD0～AD2 选通式灰度，不使用 TX/RX 串口循迹模块。PC1 的输入电平尚未完成实测核验；模块供 5 V 不代表其 OUT 可以不经核验直接接入 PC1。

上电、复位后电机保持停止。车放在标定起点，探头中间通道对准主轨道，灰度与 IMU 数据正常后，短按并松开 KEY 启动；运行中按 KEY 停止。DAP 串口为 115200、8N1，单字节 `G` 启动，`X` 停止。

[采集脚本](工程/capture_four_corners.ps1) 默认 COM14，可传 `-PortName COMxx`。它检查电机停止、中线和传感器数据后会**主动发送 G 启动车辆**，不是被动监听脚本。日志写入脚本旁的 `logs` 目录。

## 控制逻辑

本版 Makefile 启用 `GIT_VERIFIED_CORNER`：

1. 八路灰度形成加权误差，左右轮差速纠偏。
2. 在预设里程窗口内连续确认右侧直角弯图样；先前移，再差速转向，重新找到中线后恢复循迹。
3. 转角由重新找到中线决定，不是 IMU 固定转满 90°；IMU 同时参与状态记录和保护。
4. 直道宽黑图样进入短停、低速通过流程；异常图样、持续丢线、传感器数据过期或超时会停车。
5. 完成第 4 个真弯并结束恢复阶段后，报告 `FOUR_CORNERS_COMPLETE` 并停止。

## 重新编译

推荐先下载完整仓库。此小 ZIP 不含 HAL/CMSIS 和共用链接脚本，不能单独解压后直接编译。

在完整仓库的 `releases/2026-10-07_正方形循迹/工程` 内，使用 CubeIDE 随附的 GNU `make` 和 GNU Arm 工具链：

```powershell
make ROOT=../../.. all
```

若工具链路径不同：

```powershell
make ROOT=../../.. "TOOL_ROOT=C:/你的工具链目录/tools/bin" all
```

`ROOT=../../..` 将归档工程指向仓库根目录，不能省略。生成文件为 `build/F407ZGT6_FourCorner_GarageLine_Test.elf` 和 `.bin`。

目录中已有的 [BIN](工程/F407ZGT6_FourCorner_GarageLine_Test.bin) 对应现场成功固件，SHA-256：

```text

```

烧录后不会自动启动。本文档更新未重新烧录或驱动车辆。
