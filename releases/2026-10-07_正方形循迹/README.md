# 10.7 正方形循迹

本目录是 2026-10-07 现场确认正常的四弯正方形循迹测试版本。小车从 B 点出发，车头朝 C 点，收到 DAP 串口 `G` 或按板载 KEY 后启动；完成第 4 个真实右直角弯后自动停车。电机停机状态会拉低 TB6612 的 STBY。

## 本次确认结果

`测试记录/四弯_无库线_成功.csv` 是撤掉四条车库线后的完整记录：4 次 `CORNER,START`、4 次 `CORNER,DONE`，最后为 `FOUR_CORNERS_COMPLETE`。现场确认运动正常。

`测试记录/库线场景_第3弯前保护停机.csv` 保留贴有车库线时的原始记录。它在第 3 个真弯后、下一段直道中途因宽黑图样保护停机，不能当作库线场景成功记录。

## 引脚与启动

- 八路灰度：AD0 = PB12、AD1 = PB13、AD2 = PB14、OUT = PC1，模块 5V 接 5VIN，GND 接公共 GND。
- ICM：PC10 = USART3_TX，PC11 = USART3_RX，5V 和 GND 共地。
- DAP 串口：USART1，PA9 = TX、PA10 = RX，115200 8N1；发送单字节 `G` 启动、`X` 急停。
- 板载 KEY：PA15；按下启动，运行中按下停止。
- 四路电机和编码器沿用仓库当前主控接线，不在本目录重新定义驱动板线序。

## 编译和烧录

在本目录 `工程` 下使用仓库同一套 STM32CubeIDE ARM GCC 执行 `make all`。生成的 `F407ZGT6_FourCorner_GarageLine_Test.bin` 已在现场通过 CMSIS-DAP 校验。烧录前必须架空或确保车轮周围安全，烧录后程序不会自动启动。

本版本只代表“撤掉库线后的四弯正方形循迹”已验证成功；贴回车库线后，仍需重新验证库线识别和通过策略。
