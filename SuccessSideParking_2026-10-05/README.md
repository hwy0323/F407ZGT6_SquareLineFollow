## 工程与运行方式

- 主控 STM32F407ZGT6。四个电机 A/B/C/D 对应左前、左后、右后、右前；方向引脚 PD0～PD7，TIM1 PWM 为 PE9/PE11/PE13/PE14，STBY 为 PC0。编码器 A 用 PB6/PB7，B 用 PA6/PA7，C 用 PC6/PC7，D 用 PA0/PA1。PA15 为急停 KEY。
- DAP 串口接 USART1（PA9/PA10），115200 8N1；IMU 接 UART4（PC10/PC11）。本次固定路线回放依据编码器和 IMU，不要求循迹模块参与控制。
- `main.c` 是当时烧录的单步固件源码。通电后电机保持停止；电脑运行 `run_merged_replay.ps1`，经串口逐步下发 11 个动作。每步检查停稳，等待 1 秒，再发下一步。按 KEY 或发送 `X` 可停止当前动作；异常停车会终止后续步骤。
- 先将车放在第二轮入库试走的同一起点和朝向，再运行：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_merged_replay.ps1 -PauseSeconds 1`。默认串口为 `COM14`，可用 `-PortName` 指定其他串口。
- 在本仓库目录中执行 `make all` 可重建 ELF/BIN。`Makefile` 使用仓库根目录的 `Core/`、`Drivers/` 和链接脚本；ST GNU 工具链路径为本机 CubeIDE 安装路径，换电脑时需调整 `TOOL_ROOT`。
