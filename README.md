# F407ZGT6 正方形直角循迹

这是 STM32F407ZGT6 小车的低速黑线循迹工程。它基于已验证的四路 TB6612 电机接线，只处理直线纠偏和 90° 直角弯；不使用编码器、视觉识别和复杂 PID。本次工程只编译，不烧录。

灰度模块是 CD4051 八选一复用模块，并非八根独立输出线。本直连测试版用 3 根地址线和 1 根数字输入线，按顺序读取 8 个探头。

## 接线

### 电机与按键

| 功能 | F407 引脚 | D24A / 模块信号 |
| --- | --- | --- |
| 左前电机 A 方向 | PD0、PD1 | J4：AIN1、AIN2 |
| 右前电机 B 方向 | PD2、PD3 | J4：BIN1、BIN2 |
| 左后电机 C 方向 | PD4、PD5 | J6：CIN1、CIN2 |
| 右后电机 D 方向 | PD6、PD7 | J6：DIN1、DIN2 |
| 左前、右前、左后、右后 PWM | PE9、PE11、PE13、PE14 | J4：PWMA、PWMB；J6：PWMC、PWMD |
| 所有 TB6612 待机 | PC0 | J4 的 STBY；驱动板同步到四路 |
| 启动 / 停止按键 | PA15 | 板载 KEY，低电平有效 |
| 状态灯 | PC13 | 板载 LED，低电平点亮 |
| 预留视觉串口 | PA9、PA10 | USART1：PA9=TX，PA10=RX；本工程未初始化 |

### 八路灰度模块

模块由稳定的 5 V 供电，模块 GND、F407 GND 和 TB6612 逻辑地必须共地。模块 5 V 不能接到电机 12 V 端，也不能改接 F407 的 3.3 V。

| 模块端 | 中间电路 | F407 端 | 信号方向 |
| --- | --- | --- | --- |
| 5V | 稳定 5 V 电源 | 非 GPIO | 供电 |
| GND | 直接共地 | GND | 参考地 |
| AD0 | 直接连接 | PB0 | F407 → 模块 |
| AD1 | 直接连接 | PB1 | F407 → 模块 |
| AD2 | 直接连接 | PB2 | F407 → 模块 |
| OUT | 直接连接 | PB10 | 模块 → F407 |

这是没有电平转换器时的临时直连方案。商家 STM32 参考例程也把 3.3 V GPIO 直接接到 AD0、AD1、AD2；若出现通道跳变、读数始终不变或不稳定，必须补 74HCT125 / 74AHCT125 地址缓冲，不能用软件掩盖。

模块由 5 V 供电，手册没有给出 OUT 的高电平电压。直接接 PB10 前，先确认 PB10 只作数字输入，并在首次上电后用万用表测量模块 OUT 的高电平。以后补齐硬件时，应改为 NPN 反相与 3.3 V 上拉级，避免把未知的 5 V 信号直接送进 MCU。

模块 EN 已在板内经 10 kΩ 下拉，不需要也不能额外连接 GPIO。PA13、PA14 保留给 SWD，PA15 保留给板载按键。

模块通道的地址关系如下。一次扫描返回的位图中，`bit0=CH1`，…，`bit7=CH8`。

| 软件索引 | AD2 | AD1 | AD0 | 模块通道 | 位图位 |
| ---: | ---: | ---: | ---: | --- | --- |
| 0 | 0 | 0 | 0 | CH1 | bit0 |
| 1 | 0 | 0 | 1 | CH2 | bit1 |
| 2 | 0 | 1 | 0 | CH3 | bit2 |
| 3 | 0 | 1 | 1 | CH4 | bit3 |
| 4 | 1 | 0 | 0 | CH5 | bit4 |
| 5 | 1 | 0 | 1 | CH6 | bit5 |
| 6 | 1 | 1 | 0 | CH7 | bit6 |
| 7 | 1 | 1 | 1 | CH8 | bit7 |

## 程序行为

程序用 PB0、PB1、PB2 选择通道，等待 50 µs 后由 PB10 读取该通道；8 路扫描约需 400 µs。微秒延时使用 F407 的 DWT 周期计数器，不会对每个探头执行 `HAL_Delay(1)`。

`main.c` 中的 `BLACK_LINE_LEVEL` 表示 MCU 侧“压到循迹线”的电平。此车实际赛道上探头灯亮，因此直连测试版设为 `GPIO_PIN_SET`。这来自实车观察，若更换赛道必须重新标定。

先断开电机使能，只检查传感器：

1. 模块探头距赛道约 18 mm。
2. 分别让每个探头处于背景和黑线，记录 PB10 扫描出的稳定位图。
3. 将压线时的 MCU 侧电平确定为 `BLACK_LINE_LEVEL`；若为低，改成 `GPIO_PIN_RESET` 后重新编译。
4. 用一条黑线从车头左侧扫到右侧，确认 CH1～CH8 对应真实左右顺序。若车转向相反，先核对探头的实际安装方向，再调整位图顺序或权重，不能同时盲改两处。

循迹使用权重 `{-7,-5,-3,-1,+1,+3,+5,+7}` 做比例纠偏。线偏左时左轮减速、右轮加速；线偏右时相反。直角时连续识别到一侧 4 个探头压线，程序先低速前进 100 ms，再原地转向；中心探头重新压线后低速直行 100 ms，回到普通循迹。默认完成第 4 个直角后停车；将 `LAP_TURN_LIMIT` 设为 `0U` 可持续绕圈。

初始低速参数为直线 `220 / 1000`、直角前进 `180 / 1000`、原地转向 `220 / 1000`。传感器全失、大片黑区或转弯超时会立即停止四路电机并拉低 STBY。
