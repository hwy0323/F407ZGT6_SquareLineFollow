# F407ZGT6 正方形直角循迹

这是基于已实测四路 TB6612 电机接线的 STM32F407ZGT6 工程。它只处理黑线直线纠偏和 90° 直角弯：没有把直角弯当成普通偏线，也不使用编码器、视觉识别或复杂 PID。本次工程只编译，不烧录。

## 接线

| 功能 | F407 引脚 | D24A / 模块信号 |
| --- | --- | --- |
| 左前电机 A 方向 | PD0、PD1 | J4：AIN1、AIN2 |
| 右前电机 B 方向 | PD2、PD3 | J4：BIN1、BIN2 |
| 左后电机 C 方向 | PD4、PD5 | J6：CIN1、CIN2 |
| 右后电机 D 方向 | PD6、PD7 | J6：DIN1、DIN2 |
| 左前、右前、左后、右后 PWM | PE9、PE11、PE13、PE14 | J4：PWMA、PWMB；J6：PWMC、PWMD |
| 所有 TB6612 待机 | PC0 | J4 的 STBY；驱动板会同步到四路 |
| 灰度 D0～D7 | PE0～PE7 | 从车头朝前看，左到右依次连接 D0～D7 |
| 启动 / 停止按键 | PA15 | 板载 KEY，低电平有效 |
| 状态灯 | PC13 | 板载 LED，低电平点亮 |
| 后续 MaixCAM 串口 | PA9、PA10 | USART1：PA9=TX，PA10=RX；本工程仅保留，不初始化 |

灰度模块横向装在车头，传感器顺序如下：

```text
车头方向 ↑

D0  D1  D2  D3 | D4  D5  D6  D7
PE0 PE1 PE2 PE3| PE4 PE5 PE6 PE7
左侧             车体中线             右侧
```

灰度模块必须输出 3.3 V 逻辑。代码默认“检测到黑线时输出低电平”；如果模块实测相反，将 `main.c` 中的 `SENSOR_ACTIVE_LOW` 改为 `0U`。

## 运行方式

1. 先断开电机驱动电源，完成信号线与 GND 共地。
2. 让 D3、D4 对准起跑直线的黑线。
3. 接通电机驱动电源后，短按 PA15 一次开始；LED 点亮。
4. 再短按 PA15 一次，或发生传感器异常、转弯超时，四路电机停止并拉低 STBY。

默认低速参数为直线 `220 / 1000`、直角前进 `180 / 1000`、原地转向 `220 / 1000`。它通过黑线重心做比例纠偏：黑线出现在左侧时左轮减速、右轮加速，反之亦然。

进入直角时，D0～D3 或 D4～D7 会连续三次整片压到黑线。程序先低速前进 100 ms，再原地向对应方向转，检测到 D3 或 D4 重新压线三次后低速直行 100 ms，回到普通循迹。每通过一个角点计数一次，默认第 4 个角点后自动停车。若需持续绕圈，把 `LAP_TURN_LIMIT` 改为 `0U`。

第一次实车前建议记录直线、左直角、右直角三种情况下的 8 位灰度输出。如果直角时不是整片 4 个传感器有效，可修改 `Detect_Corner()` 中的条件；如果黑胶带较宽，可适当把 `REACQUIRE_MAX_ACTIVE` 从 `2U` 调大。
