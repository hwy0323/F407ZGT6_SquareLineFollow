## 10.7 正方形循迹怎样运行

1. 使用下表接线，烧录 [10.7 固件](releases/2026-10-07_正方形循迹/工程/F407ZGT6_FourCorner_GarageLine_Test.bin)。上电、复位后电机保持停止。
2. 放在本次标定的 B 点，车头朝 C 点，探头中间通道对准主轨道。此次成功复测已撤掉 4 条车库线。
3. 短按并松开 PA15 板载 KEY，或通过 DAP 串口发送单字节 `G`。程序检查灰度和 IMU 数据后启动。
4. 正常纠线，通过第 4 个真实右直角弯后自动停车。运行中按 KEY 或发送 `X` 可停止。

本版是 **4 弯一圈**，不是旧说明中的 8 弯两圈。停止状态会拉低 PC0（STBY）。

需要电脑记录时，可在 `releases/2026-10-07_正方形循迹/工程` 内运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\capture_four_corners.ps1 -PortName COM14
```

把 `COM14` 改为实际串口。**该脚本检查通过后会主动发送 G 启动车辆，并非只读日志。** 串口格式为 115200、8N1，记录写入脚本旁的 `logs` 目录。

## 当前实测线束

适用于上表成功版本，正方形循迹的入口源码位于 [工程/main.c](releases/2026-10-07_正方形循迹/工程/main.c)。A/B/C/D 是驱动板电机接口，不能按旧版“左前、右前、左后、右后”顺序理解。

| 驱动板接口／车轮 | 方向 IN1 / IN2 | PWM | 编码器 A / B |
| --- | --- | --- | --- |
| Motor A／左前 | PD0 / PD1 | PE9／TIM1_CH1 | PB6 / PB7／TIM4 |
| Motor B／左后 | PD2 / PD3 | PE11／TIM1_CH2 | PA6 / PA7／TIM3 |
| Motor C／右后 | PD4 / PD5 | PE13／TIM1_CH3 | PC6 / PC7／TIM8 |
| Motor D／右前 | PD6 / PD7 | PE14／TIM1_CH4 | PA0 / PA1／TIM2 |

| 模块信号 | STM32 引脚／接法 |
| --- | --- |
| 四路驱动 STBY | PC0 |
| 八路灰度 AD0 / AD1 / AD2 | PB12 / PB13 / PB14 |
| 八路灰度 OUT | PC1 |
| 八路灰度 5V / GND | 5VIN / 公共 GND |
| IMU R（接收） | PC10／UART4_TX |
| IMU T（发送） | PC11／UART4_RX |
| IMU V / G | 5V / 公共 GND |
| DAP RXD（接收） | PA9／USART1_TX |
| DAP TXD（发送） | PA10／USART1_RX |
| 板载 KEY | PA15，低电平按下 |
| 板载 LED | PC13，低电平点亮 |
| SWDIO / SWCLK / RST | PA13 / PA14 / NRST，另接公共 GND |

IMU 使用 **UART4，不是 USART3**。八路灰度是带 AD0～AD2 和 OUT 的选通式模块，不是 TX/RX 串口循迹模块，8 路均参与判断。

主控、驱动板和各模块必须共地。电机电源与逻辑电源分开接；12 V 不能接到 5 V 或 GPIO。灰度模块的供电为 5 V，但 OUT 高电平尚未实测，不能据此认定 PC1 可直接承受 5 V；制作 PCB 前仍须核对电平并设计保护。旧 PCB 规划不作为本版本接线依据。

## 正方形循迹逻辑与里程

10.7 使用 `GIT_VERIFIED_CORNER` 分支：八路灰度计算偏差，左右轮差速纠线；在预设里程窗口内确认右直角弯，先前移，再差速转向，探头重新找到中线后恢复循迹。它**不是每弯都靠 IMU 精确转满 90°**。

直道宽黑图样有单独的短停和低速通过逻辑，但 `PARKING_LINE` 日志名不等于现场必有车库线：普通轨迹也可能被多个探头同时看到。贴回车库线后的完整四弯流程尚未验证成功。

以下是编码器 A 从启动点累计的正向计数，**不是厘米，也不是相邻两点间距**：

| 数据来源 | 位置 | 累计计数 |
| --- | --- | --- |
| 无库线成功四弯记录 | C1 / C2 / C3 / C4 | 5025 / 11374 / 17764 / 24052 |
| 贴库线测试记录 | 倒车入库两条库线 | 1402 / 3175 |
| 贴库线测试记录 | 侧方停车两条库线 | 13624 / 14862 |

第 5 次额外识别已由现场确认是误判，已从库线清单剔除；原始日志保留用于追溯。上述数据来自不同次试跑，不应当作同一次运行的全部坐标。

固件当前判弯窗口中心仍为 `5100 / 11299 / 17567 / 23793`，半宽 `900` 计数；这与最新实测里程是两组不同数据。本次整理没有擅自改动这些参数。详细证据见 [10.7 说明与记录](releases/2026-10-07_正方形循迹/README.md)。

## 编译与下载

建议下载整个仓库，保留 `Core/`、`Drivers/` 和链接脚本等共用依赖。10.7 的小 ZIP 包含入口源码、固件和记录，**单独解压不足以重编译**，仍需上述仓库依赖；10.6 的完整交付 ZIP 已按其说明打包同级依赖。

在仓库根目录打开 PowerShell，确保 CubeIDE 随附的 GNU `make` 可用，然后：

```powershell
cd "releases/2026-10-07_正方形循迹/工程"
make ROOT=../../.. all
```

如 GNU Arm 工具链安装路径不同，覆盖 `TOOL_ROOT`：

```powershell
make ROOT=../../.. "TOOL_ROOT=C:/你的工具链目录/tools/bin" all
```

生成文件在该目录的 `build/` 中。不要直接在仓库根目录编译来替代 10.7 工程。其他版本的编译和回放步骤见各自 README。

## 已测硬件与后续工作

当前成功流程使用 STM32F407ZGT6、T5X 四驱差速底盘、4 路 TB6612、GT50 霍尔编码器电机、八路选通式灰度模块、串口 IMU 和无线 DAP。接线及验证范围也随 10.6 完整交付包提供。

OLED、视觉、激光测距和云台不参与上述 10.7 正方形测试。仓库有历史资料不代表已经集成为同一套自动任务。后续应以这些成功版本为基线，分别验证贴库线抗干扰、停车与循迹衔接，再整合任务菜单。
